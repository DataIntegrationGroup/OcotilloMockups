Design System
Every class in ocotillo.css, rendered. Ported from OcotilloUI — see README.md for provenance and rules.
This is the reference, not a mockup. Build screens from these classes. If something you need is missing, add it to the stylesheet when it is general, and to your mockup's own <style> block when it is one-off.

Badges / chips

.badge | .chip + variant
Tinted at 10% with a 30% border of the same token, via color-mix. Never hand-picked hex pairs — those drift from the token and break dark mode.
Default Primary Success Warning Destructive Info Neutral Outline
Domain flags — water chemistry meanings mapped onto those tints:
Above MCL Above SMCL ND Calc. Below limit Expiring
