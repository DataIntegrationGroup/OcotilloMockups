Field Planning
Reserve unique well IDs before a field trip  ·  AMP water well inventory  ·  Editor and above
Lo-fi mockup — for feedback only. Visualizes ADR 0002 — Well ID Minting Service. Nothing here is built; the backend table, mint endpoint, and list endpoint do not exist yet. Open questions this mockup takes a position on (all still up for debate):
  • Prefix is a free-text combobox autocompleting against prefixes already seen in thing.name — no prefix registry, not tied to Project/Group.
  • Table is team-wide by default. "Minted by me" is a filter chip, not a boundary — you need to see everyone's IDs to answer "has anyone got WL-0048?".
  • Shows a Release row action (ADR lists manual release as undesigned — this is a proposal, not a decision).
  • 90-day TTL shown as a countdown chip once inside 14 days. Duration is still a placeholder.
